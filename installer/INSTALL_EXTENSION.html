Installer l’extension Correctly

Le serveur est installé. L’extension doit être ajoutée séparément dans Chrome ou Brave.

  1. Extrayez Correctly-Extension.zip dans un dossier permanent que vous conserverez.
  2. Ouvrez chrome://extensions dans Chrome ou brave://extensions dans Brave.
  3. Activez le mode développeur, cliquez sur « Charger l’extension non empaquetée » et sélectionnez le dossier dist extrait.
  4. Rechargez vos pages et laissez l’icône Correctly près de l’horloge active. Essayez « je sui content » ou « I has a car ».

Si le navigateur est géré par une organisation, respectez sa politique d’installation. Le setup ne modifie ni les profils ni les politiques du navigateur.

Vos textes sont corrigés localement. Aucun compte n’est nécessaire. Si le serveur indique « port occupé », quittez l’ancienne version Correctly avec son propre menu avant de démarrer celle-ci.
