## 1. Product decision and acceptance contract

### 1.1 Mission

Like Google Translate's bubble in Chrome: when the user selects text on a
page, a small Correctly button appears at the end of the selection. Short
selections are translated in a small bubble; longer ones open the Correctly
window directly on the Translation tab.

### 1.2 New V5.15 functionality

- **Selection button.** After a mouse or keyboard selection of page text (or
  text inside an ordinary text field), a small round button with a
  translation icon appears just above the end of the selection. It
  disappears on click elsewhere, scroll, Escape, typing, or when the
  selection is cleared. It never appears in password or sensitive fields
  (same exclusions as the content script), in the Correctly window itself,
  or for an empty/whitespace selection.
- **Short selection (1 to 5 words):** a click opens a small bubble next to
  the selection and sends **one** translation request (the existing
  `correctly.v5.translateText` message, neutral style). The bubble shows:
  the translation, **To** language (and Arabic variant) selectors
  pre-filled from the settings, **Copy**, and **Open in Correctly** (opens
  the window on the Translation tab with the same text). Changing the
  language in the bubble sends a new request only after an explicit
  "Translate" click.
- **Long selection (more than 5 words):** a click opens the Correctly window
  directly on the **Translation** tab with the selection as its text and
  **starts the translation at once** (owner decision D5): the click on the
  button is the explicit action; one request per click.
- **Setting:** "Show a translate button on selected text", off by default,
  in Settings → Getting started → Opening Correctly, next to the handle. It
  requires the existing optional all-sites access (asked when turned on,
  released when nothing needs it any more).
- Bilingual UI (fr/en): bubble, tooltip, accessible names, setting.

### 1.3 Non-goals

- No automatic translation on selection, hover or page load.
- No whole-page translation, no replacement of page text (bubble is
  copy-only).
- No new provider, permission, host or dependency; no change to the
  translation prompt or to the V5.8 counting rules.
- No button inside cross-origin frames the user has not granted, PDF viewer,
  `chrome://` pages or the Web Store (Chrome forbids them).

### 1.4 Required examples

| Selection                                | Click                    | Expected                                                        |
| ---------------------------------------- | ------------------------ | --------------------------------------------------------------- |
| "Qu'est-ce que" (3 words) on an article  | translate button         | bubble, one request, English (settings default) translation     |
| same, then To = Arabic / Syrian, Translate | Translate in the bubble | one more request, Syrian Arabic result, RTL                     |
| same, then "Open in Correctly"           | link in the bubble       | window opens on Translation with "Qu'est-ce que", nothing sent  |
| a 40-word paragraph                      | translate button         | window opens on Translation with the paragraph and translates it (one request) |
| selection in a password field            | —                        | no button                                                       |
| setting off                              | —                        | no button, no listener installed                                |
| consent not given or no route            | translate button         | bubble shows the existing message (consent / settings), nothing sent |

## 4. Functional design

- **Word count:** `Intl.Segmenter(locale, { granularity: 'word' })`,
  counting `isWordLike` segments (works for French, Arabic, Turkish…); text
  trimmed; > 500 code points always counts as long.
- **Button position:** from `Range.getClientRects()` of the selection: last
  rect, above its right end (below when there is no room), clamped to the
  viewport; `position: fixed`, closed shadow root, highest z-index, 28 px.
- **Keep the selection:** the button and bubble cancel `mousedown` so the
  page selection is not lost before the click.
- **Bubble:** closed shadow root, ~320 px wide, same visual language as the
  5.14.1 window (tokens, light/dark), `role="dialog"`, labelled; Escape and
  outside click close it; focus returns to the page.
- **Request:** `{ type: TRANSLATE_TEXT, text, source: 'auto', target,
  variant, styleIds: [] }`; one in flight at a time; result text inserted
  with `textContent` only, `dir="auto"`.
- **Open in Correctly / long selection:** new bare message
  `correctly.v5.openTranslation` (exact shape `{ type, text }`, text ≤ 2,000
  code points) from the content-script sender → worker `correctInTab(…,
  'open')` with an initial tab and text, → `openModal(doc, { …, tab:
  'translation', text })`. The window must accept the text passed this way
  as a read-only page source (copy only), exactly like a captured page
  selection.

## 5. Data model and storage

- `correctly.v5.settings`: new field `triggers.selectionButton` (boolean,
  default `false`, `normalizeSettings` → `false` when absent or invalid).
- **Sync:** not synced, like `smartButton` (it needs site access granted on
  each computer). Add it to the never-synced list (`pickSettings`).
- `pageConfig()`: adds `selectionButton` and the translation defaults
  (`target`, `arabicVariant`); `toPageConfig()` normalizes them.
- `syncSmartScript()` and the settings page's `releaseSiteAccess()` count
  the new setting as a reason to keep the script and the site access.

## 6. Messages and security

- `TRANSLATE_TEXT` from `smart.js` is accepted like from `content.js`
  (`isContentScriptSender`): same guard, same controller path, consent and
  limits unchanged.
- New `OPEN_TRANSLATION` message: content-script sender only, exact shape,
  nothing replied, nothing sent to a provider.
- The bubble never reads page content other than the user's selection; no
  log; no key or route in the page.

## 7. Limits, statistics and sync

- Each bubble translation = one `translation` request in limits and
  statistics (route of the Translation action). Opening the window counts
  nothing.
- No change to sync domains except excluding `selectionButton` (§5).

## 8. User interface (fr/en)

## 13. Risks

| Risk                                          | Mitigation                                                        |
| --------------------------------------------- | ----------------------------------------------------------------- |
| Button felt as intrusive                      | off by default, small, disappears quickly, never over inputs' text |
| Accidental paid requests                      | a click is required; one request per click; limits apply          |
| Selection lost when clicking the button       | `mousedown` prevented on button and bubble                        |
| Pages with odd layouts (transforms, iframes)  | fixed positioning from client rects, clamped; manual checklist    |
| Conflict with Chrome's translate bubble       | placed above the selection end, offset; manual check              |
