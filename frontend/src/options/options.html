Démarrage

Correctly corrige, reformule, traduit ou résume le texte que vous sélectionnez, uniquement quand vous le demandez, et développe vos raccourcis texte localement.

  1. Ajoutez une clé API Google Gemini ou OpenAI, dans Fournisseurs IA.
  2. Autorisez l’envoi La case ci-dessous : sans elle, rien n’est jamais envoyé.
  3. Sélectionnez du texte et ouvrez Correctly Bouton de la barre d’outils, Ctrl+M ou la poignée au bord droit de la page.

Envoi du texte à l’IA

Comment ça marche

La sélection est copiée dans la fenêtre Correctly ; elle n’est envoyée que quand vous cliquez sur un bouton Générer. Rien ne change dans la page tant que vous ne cliquez pas sur Appliquer, disponible dans les zones de texte simples ; ailleurs, copiez le résultat. Le texte d’un article peut être sélectionné pour le traduire ou le résumer (copie seulement). Les champs mot de passe, e-mail, téléphone, URL, nombre et recherche ne sont jamais lus. Chaque génération compte comme une requête dans vos limites d’usage et peut être facturée par votre fournisseur. Les suggestions peuvent être fausses : vérifiez-les.

Ouvrir Correctly

Le bouton de la barre d’outils ouvre toujours la fenêtre Correctly. L’IA n’est appelée qu’après une action de votre part.

Certaines combinaisons sont réservées par le navigateur ou d’autres applications.

Fournisseurs IA

Utilisez vos propres clés API Google Gemini et/ou OpenAI, puis choisissez la clé et le modèle de chaque action. Les abonnements ChatGPT et Gemini grand public sont séparés et ne paient pas les appels API.

Clés API

Aucune clé API enregistrée. Ajoutez-en une pour utiliser la correction, la reformulation, la traduction et le résumé. Les raccourcis texte fonctionnent sans clé.

    Ajouter une clé API

    Les espaces avant ou après la clé sont retirés. Enregistrer n’envoie rien. Créer une clé dans Google AI Studio.

    Les clés sont stockées localement dans ce profil de navigateur (non synchronisées, jamais exportées, jamais réaffichées). Ce n’est pas un coffre-fort : toute personne ayant accès à ce profil ou à cet ordinateur peut les lire. Fixez des plafonds de dépense chez votre fournisseur et changez une clé en cas de doute.

    Clé et modèle de chaque action

    Chaque action utilise exactement la clé et le modèle choisis ici (ou la route par défaut). Si cette clé manque, est désactivée ou refusée, l’action s’arrête avec un message : Correctly ne passe jamais tout seul à une autre clé, un autre modèle ou un autre fournisseur et ne réessaie jamais seul. « Vérifier » est gratuit ; « Tester » envoie un tout petit message et peut être facturé.

    Tarifs : Gemini, OpenAI. Ils changent et dépendent de votre compte.

    Actions

    Les choix par défaut des onglets Reformulation, Traduction et Résumé. Vous pouvez les changer à chaque fois avant de générer.

    Reformulation

    Styles cochés par défaut

    Tous les styles choisis sont produits par une seule requête IA, dans la langue de votre texte (pas de traduction).

    Traduction et résumé

    Langues par défaut de l’onglet Traduction (et du menu clic droit). L’onglet Résumé démarre avec la même langue cible et la même variante d’arabe, et écrit le résumé directement dans cette langue, en une requête.

    Une requête IA par traduction (détection de la langue comprise). Le syrien est l’arabe parlé au quotidien ; l’arabe standard moderne est la norme écrite. Une traduction automatique peut être fausse : relisez-la avant d’envoyer quelque chose d’important.

    Raccourcis texte

    Tapez un raccourci suivi d’un espace ou de , ; : . ! ? pour le remplacer localement — sans internet, sans IA, sans quota.

    Jamais au collage, à Tab ou Entrée, ni dans les champs mot de passe, paiement, code ou éditeurs riches. Les raccourcis restent dans ce profil de navigateur (non synchronisés) : exportez une sauvegarde.

      Chargement…

      Les limites enregistrées sont absentes ou endommagées : aucune requête IA n’est envoyée. Restaurer les valeurs sûres conserve tout l’usage enregistré.

      L’horloge de votre ordinateur a reculé depuis la dernière requête : les requêtes IA sont en pause (un changement d’heure ne doit pas remettre les limites à zéro). Vérifiez la date et l’heure, puis confirmez.

          À propos

          • Correctly ne lit la sélection d’une page que quand vous l’ouvrez (bouton de la barre d’outils, Ctrl+M, poignée ou menu clic droit), ne l’envoie que quand vous cliquez sur Générer, et ne modifie la page que quand vous cliquez sur Appliquer.
          • Le texte sélectionné sur un article est en lecture seule : il peut être traduit ou résumé et copié, jamais remplacé dans la page.
          • Les requêtes OpenAI sont envoyées avec store: false (non conservées pour être relues) ; ce n’est pas une garantie de non-conservation.
          • Documentation : docs/ dans le dépôt du projet.
