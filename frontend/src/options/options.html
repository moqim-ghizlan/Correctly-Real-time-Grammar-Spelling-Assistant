Correctly corrects, rewrites or translates the text you select, on request only, and expands your personal text shortcuts locally.

AI providers

    Add an API key

    Spaces before or after the key are removed. Saving sends nothing. Create a key in Google AI Studio.

    Personal-use keys are stored locally in this browser profile (not synced, never exported, never shown again). This is not server-grade secret storage: anyone with access to this profile or computer may read them. Do not share this profile or publish keys; set spending limits at your provider and rotate a key if in doubt.

    Which key and model each action uses

    Each action uses exactly the key and model chosen here (or the default route). If that key is missing, disabled or refused, the action stops with a message: Correctly never switches to another key, model or provider by itself and never retries on its own. Gemini and OpenAI are different companies: the selected text goes only to the provider of the route used. “Check key” is free; “Test” sends one tiny prompt and may be billed.

    Prices: Gemini pricing, OpenAI pricing. Correctly does not show prices: they change and depend on your account.

    Correction

    How to use: select text on a web page (up to 2,000 characters), then click the Correctly toolbar button. Only the selection is sent, only on that click. Nothing changes until you click Apply, which is available in plain text boxes; elsewhere, copy the suggestion. Password, email, phone, URL, number and search fields are never read. Each correction counts toward the daily limit below and may incur charges from your provider. Suggestions can be wrong: check them.

    Correction shortcuts & entry points

    AI is called only after you activate Correctly. Each call may count against your provider usage. The toolbar button always works.

    Some key combinations are reserved by the browser or other apps.

    Rewrite

    Styles selected by default

    You can change the styles each time before generating. All chosen styles are produced by one AI request (one request in the daily limit), in the language of your text — no translation. Rewrites need an internet connection and may incur charges; they are suggestions to review, and nothing changes until you click Apply.

    Translation

    Defaults for Translate and Translate & rewrite (right-click menu, smart button ⇄, optional shortcut). You can change them each time before translating. Translate & rewrite uses the rewrite styles chosen above.

    One AI request per translation (language detection included). Syrian colloquial is everyday spoken Arabic; Modern Standard Arabic is the formal written standard. Machine translation can be wrong: review it before sending anything important.

    Text shortcuts

    Type a shortcut followed by a space or , ; : . ! ? to replace it locally — no internet, no AI, no quota. Never on paste, Tab or Enter, and never in password, payment, code or rich editors. Shortcuts are stored only in this browser profile (not synced): export a backup.
