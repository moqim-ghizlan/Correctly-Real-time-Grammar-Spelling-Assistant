## Plan changes demanded by reality

- No popup and no separate settings site: the options page gets two new
  sections ("AI providers", "Which key and model each action uses").
- Writes follow the V5.6 pattern (Web Lock + read-back verification) instead
  of a worker-side write facade: the options page is already a trusted
  extension page, and no key ever crosses a message.
- The V5.1 connection record (`correctly.v5.connection`) described one key;
  it is replaced by per-profile key checks (`correctly.v5.keyChecks`).
- Usage stays a per-day aggregate (no unbounded event log); attribution per
  provider/profile/revision/model/task is added inside the same record.
