## 4. User workflows

- **Opening the picker:** right-click **Correctly → Rewrite selected text…**,
  click the smart button's ✎, or press the rewrite shortcut. The shortcut is
  unassigned by default; set it in `chrome://extensions/shortcuts`.
- **Correction is unchanged:** the toolbar button, Alt+Shift+C, the
  "Correct selected text" menu item and ✓ all behave exactly as in V5.3.
- **Picker:**
  - It shows the original text and 7 style checkboxes, with the default
    styles pre-checked.
  - **Generate rewrites** is disabled while no style is checked.
  - Opening the picker or changing styles sends nothing.
- **Generate:**
  - One request covers all checked styles, which are sent in catalog order.
  - The inputs stay locked while it runs, so a double click is ignored.
  - **Cancel** closes the picker; a late answer is then ignored.
- **Results:**
  - There is one radio card per style, labeled from the trusted catalog,
    never from the model. Cards follow the requested order, whatever order
    the model returns.
  - The first usable card is pre-selected. Choosing a card never edits the
    page.
  - A rewrite identical to the source reads "No meaningful rewrite was
    generated for this style" and cannot be selected.
  - Styles the model did not return are listed as missing.
  - If a number, link or email changed, that card is Copy-only.
- **Apply, Copy and Undo:** the V5.2 code, unchanged. Apply goes through the
  same stale, IME, read-only and field checks. Undo is labeled "Undo
  rewrite".
- **Errors:** the panel shows the fixed message, "Your text was not changed",
  and a **Try again** button. Nothing is retried automatically.

## 5. Request contract

- Endpoint: same as V5.1 (`…/v1beta/models/{model}:generateContent`,
  `x-goog-api-key` header), with the model chosen in the settings.
- `systemInstruction`: the rewriting rules (same language, preserve facts,
  names, numbers, negations, URLs, placeholders; no translation) plus the
  requested catalog styles. The user's text travels only as the `user` part.
- `generationConfig`: `temperature: 0.7`, `responseMimeType:
'application/json'`, `maxOutputTokens = 512 + styles × (2 × code points +
64)`. The timeout is 60 s, with no retry.
- Expected reply: `{"candidates":[{"styleId":"…","text":"…"}]}`.
- Validation:
  - The whole reply is rejected if it has extra keys, a malformed entry, an
    unrequested or duplicate style, an empty text, or an output longer than
    3× + 200 code points.
  - A requested style that is absent is reported as missing.
  - A truncated or blocked answer (`finishReason` other than `STOP`) is
    rejected.
- `responseSchema` is still not sent: it was not verifiable in the official
  docs, as already noted for V5.2.
- Single-call evidence: unit tests show exactly one `fetch` for 1, 3 and 7
  styles, each counted as one attempt (tokens recorded once). The worker
  test shows one call for 3 styles, and smoke step C03 shows one message for
  2 styles.

## 6. Safety and privacy

- The key stays in the worker. The page receives only candidate texts that
  the page itself re-validates.
- Text is sent only after an explicit **Generate rewrites**, with consent
  given. Sensitive fields and plain page text are refused before the picker
  opens.
- Prompt-injection text in the selection never reaches the instruction, and
  the style list comes from the validated catalog only.
- Model output is rendered with `textContent` (HTML stays inert), and text
  blocks use `dir="auto"` for Arabic and other right-to-left scripts.
- Nothing is persisted: tests check that storage holds no source text.

## 7. Settings

- `correctly.v5.settings.rewrite`, defaulting to
  `{ enabled: true, defaultStyles: ['professional'] }`.
- Unknown IDs are dropped and duplicates collapsed, with order kept; an empty
  or corrupt value falls back to Professional.
- The settings page refuses to save an empty default set.
- When rewrite is off, the menu item is hidden, and the shortcut or ✎ shows
  "Rewrite is turned off".

## 9. Remaining risks

- Rewrite quality, including humor in serious contexts and language
  preservation for Arabic and Turkish, depends on the model. It needs the
  manual corpus review in `MANUAL_CHECKLIST.md`.
- The protected-token check covers numbers, links and emails only. It does
  not cover negations, names or uncertainty words, so review each rewrite
  before applying it.
- Input of only a URL or code is not specially blocked. It is sent if
  selected, and the preserve-identifiers rule applies.
- On a page where `smart.js` and `content.js` are both loaded, the bundle
  that runs last owns the panel. They share one global, so there are no
  duplicate requests.
