## Changements et fabrication

- Branche `feature/v3.1-installer`, créée sans effacer les modifications V3 existantes. Le paquet V3 original et sa JVM active restent conservés.
- Serveur 3.1.0 : ajout de `--shutdown`, qui compare le chemin complet de l’image du processus et envoie le message d’arrêt normal uniquement au tray correspondant, puis attend sa sortie. Aucun arrêt par nom, aucun kill global. Les hooks de setup/uninstall refusent de poursuivre si cette fermeture échoue.
- Les smoke tests explicitement lancés sur un port de test disposent d’un mutex distinct, pour vérifier le nouvel EXE sans perturber le tray utilisateur actif. Deux smoke tests sur le même port restent exclusifs ; le mutex de l’application normale est conservé.
- Raccourci `Correctly.lnk` partagé entre le setup et le menu tray, avec le marqueur de propriété V3 existant. Le setup protège les liens étrangers et conserve l’état effectivement modifié depuis le tray lors d’une mise à jour. Un ancien lien V3 n’est retiré que s’il vise cette installation et porte le marqueur attendu.
- `installer/Correctly.iss` : AppId stable, installation HKCU sans élévation par défaut, Windows 10/11 x64, bundle récursif complet, lancement final facultatif, notices, guide extension local et suppression limitée aux fichiers gérés. Pas de service ni de modification de PATH ou des profils navigateur.
- Build : `scripts/build-installer.ps1`, validation des chemins, de l’EXE GUI x64 et des 2 350 fichiers ; tous les checksums runtime/engine restent ceux du lock. Staging neuf à chaque fabrication, anciennes sorties archivées sans nettoyage global.
- Outil réellement installé : Inno Setup **6.7.3**, sous `artifacts/tools/InnoSetup-6.7.3`, installation utilisateur sans élévation. Téléchargement officiel `https://github.com/jrsoftware/issrc/releases/download/is-6_7_3/innosetup-6.7.3.exe`, SHA-256 `9c73c3bae7ed48d44112a0f48e66742c00090bdb5bef71d9d3c056c66e97b732`, signature Authenticode **Valid**, éditeur **Pyrsys B.V.**. Le moteur compilateur confirme 6.7.3 ; le script vérifie aussi sa version ISPP réelle. Le compilateur affiche « Non-commercial use only » ; examiner les conditions de l’éditeur pour un usage commercial.

## Conditions de diffusion

Une fabrication réussie ne remplace pas la recette Windows vierge, le reboot/autostart, les parcours Chrome/Brave sur sites ni la vérification de provenance/licences avant diffusion publique. Le setup ne publie ni n’installe silencieusement l’extension.

Les EXE Correctly/setup sont non signés ; comportement SmartScreen/Defender non validé. Toutes les notices du bundle et celle d’Inno Setup sont incluses ; leur présence ne certifie pas la provenance des archives V2 originales ni toutes les obligations de diffusion publique.
