# Installer Correctly 3.1 sur Windows

1. Ouvrez **Correctly-V3.1-Setup.exe**. Gardez le dossier proposé ou choisissez un dossier permanent. Aucun Java, Python ou Node.js séparé n’est nécessaire.
2. Laissez **Démarrer Correctly à l’ouverture de session** coché si vous voulez qu’il démarre avec votre session Windows. Cliquez sur Installer, puis choisissez de lancer Correctly.
3. [Installez l’extension Chrome/Brave](INSTALL_EXTENSION.md) séparément et rechargez les pages où vous écrivez.

L’installation concerne votre compte Windows, sans élévation par défaut. L’icône près de l’horloge devient verte lorsque le moteur est prêt. Gardez-la active ; **Quitter arrête aussi le serveur de correction**. Le menu permet d’arrêter, redémarrer, tester le français et l’anglais, consulter les versions ou ouvrir les diagnostics.

Pour désactiver le lancement à la connexion Windows, décochez **Démarrer avec Windows** dans le menu. Vous pouvez aussi décocher cette tâche lors d’une réinstallation. Le setup tient compte du raccourci réellement présent lors d’une mise à jour.

Le moteur inclus utilise LanguageTool et sa JVM privée ; les textes passent uniquement par `127.0.0.1:8081`. Aucun téléchargement ne se produit à l’installation ou au lancement. Les corrections fonctionnent hors ligne.

Si vous utilisiez une ancienne version, quittez-la via son menu et désactivez son démarrage automatique avant de lancer la nouvelle. Un **port occupé** indique qu’un autre serveur utilise 8081 ; Correctly ne l’arrête pas. Un ancien raccourci géré par une autre installation est conservé et peut bloquer le setup pour éviter un lancement en double.

Pour désinstaller, ouvrez **Paramètres Windows → Applications → Correctly → Désinstaller**. Le programme ferme uniquement sa propre instance, retire son raccourci de démarrage et ses fichiers installés. Vos paramètres et votre dictionnaire dans le navigateur sont conservés. Les journaux dans `%LOCALAPPDATA%\Correctly` restent disponibles ; retirez l’extension séparément si souhaité.

Le setup et l’application ne sont actuellement pas signés. Les contrôles SmartScreen et antivirus dépendent de Windows et n’ont pas été validés ici ; respectez les protections du système. Les avis de composants inclus sont dans `licenses` et `runtime/legal`.

Statut : **candidate implémentée, recette partielle**. L’essai sur Windows vierge, la reconnexion/reboot et les parcours manuels Chrome/Brave restent des conditions de validation finale.
