# Correctly 5.13.0 — Release notes

## New: English and French interface

- New setting **Interface language** (Settings → Getting started):
  _Automatic_ (follows the browser: French for a French browser, English
  otherwise), _Français_ or _English_. The settings page switches at once;
  already open web pages use the new language from their next opening of
  Correctly.
- Translated: the whole settings page (static text, messages,
  confirmations, errors, limits and statistics wording, dates and numbers),
  the in-page Correctly window and V5.2–V5.5 panel, the right-edge handle,
  the Undo toast, quota warnings and the right-click menu titles.
- Not translated on purpose: the instructions sent to the AI, the CSV/JSON
  statistics exports (data), model IDs and provider names. The browser's own
  command descriptions (chrome://extensions/shortcuts) stay in English.

## Under the hood

- Catalogs: `shared/i18n.ts` (shared wording), `content/messages.ts`,
  `options/messages.ts`; the static settings page is generated by
  `scripts/i18n-options.mjs` (French default text + `data-i18n` keys).
- Shared validation now returns codes (`ProviderError`, `ShortcutError`,
  range and key-combination problems) worded by the page; no French or
  English text is hard-coded in shared modules any more.
- Inline markup of the page (bold, keys, code, in-page links) is rebuilt
  node by node from an allowlist; no `innerHTML`.
- Settings schema: new `ui.language` (default `auto`); older settings read
  as `auto`. No new permission, host or dependency.
